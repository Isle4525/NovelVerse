NovelVerse
Каталог Профиль Новелла

Создать книгу

Работает с endpoint `POST /novels`

Редактировать книгу

Работает с endpoint'ами `GET /novels/{id}`, `PUT /novels/{id}` и `DELETE /novels/{id}`

Добавить главу

Работает с endpoint `POST /chapters`

Редактировать главу

Работает с endpoint'ами `GET /chapters/novel/{id}`, `GET /chapters/{id}`, `PUT /chapters/{id}` и `DELETE /chapters/{id}`

Загрузить PDF

Работает с endpoint `POST /pdf/upload` и парсит главы асинхронно

Новеллы в базе

Список из `GET /novels` для быстрого контроля и перехода
